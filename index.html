Kosongkan kolom ini untuk menggunakan Data Simulasi (Mock Data).

Cara Setup:

  1. Buka Google Spreadsheet, buat sheet bernama DataPenjualan
  2. Buat header: Tanggal, Store, Department, Artikel, Description, Qty, Value
  3. Klik Ekstensi > Apps Script
  4. Paste kode Code.gs (disediakan di tab editor)
  5. Klik Terapkan (Deploy) > Deployment Baru
  6. Pilih jenis Aplikasi Web, akses Siapa saja
  7. Copy URL berakhiran /exec dan paste ke kotak di atas.
